# Congratulations website with your bouquet video

This version replaces the hand-drawn rose SVG with your exact uploaded sunflower bouquet video, displayed in the Congratulations tab. The Open Letter and Fireworks Celebration tabs remain.

## Publish on GitHub Pages
1. Upload BOTH `index.html` and `bouquet.mp4` into the root of your GitHub repository.
2. In GitHub Settings → Pages, select Deploy from a branch → main → /(root), and Save.
3. Wait for deployment, then visit your published Pages URL.

Keep the video filename exactly `bouquet.mp4`. It loops automatically without sound and is mobile-friendly. You can customise the letter text in `index.html`.
